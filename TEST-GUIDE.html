🧪 Guide de Test - Fantasy Map Generator

Suivez ces étapes pour tester toutes les corrections apportées

🗺️ Ouvrir l'Application 🧪 Tests Automatiques 🧹 Clear Cache

📂 Test 1: Ouverture de l'Application

🔴 CRITIQUE
  • Ouvrir http://127.0.0.1:8000 dans votre navigateur
  • La page se charge sans erreur 404
  • L'écran de chargement s'affiche
  • Une carte apparaît après quelques secondes

🖥️ Test 2: Console du Navigateur

🔴 CRITIQUE - Ouvrir DevTools (F12)
  • Appuyer sur F12 pour ouvrir DevTools
  • Aller dans l'onglet "Console"
  • Pas d'erreurs ROUGES critiques
  • Messages de timing visibles (TOTAL: ~X.XXs)
🟡 IMPORTANT - Vérifier les variables

Dans la console, taper ces commandes:

VERSION
// Devrait afficher: "1.108.12"

typeof drawFeatures
// Devrait afficher: "function"

typeof pack
// Devrait afficher: "object"
  • VERSION affiche "1.108.12"
  • drawFeatures est une "function"
  • pack est un "object"

🗺️ Test 3: Génération de Carte

🔴 CRITIQUE - Vérification Visuelle
  • Vous voyez des TERRES (zones colorées)
  • Vous voyez l'OCÉAN (zones bleues)
  • Vous voyez des PAYS (frontières visibles)
  • Vous voyez des VILLES (points/icônes)
  • Vous voyez des RIVIÈRES (lignes bleues)
  • Les labels (noms) s'affichent

⚠️ Si vous ne voyez QUE l'océan → ÉCHEC (bug pas corrigé)

🟡 Générer une Nouvelle Carte
  • Cliquer sur "Tools" ou le bouton hamburger (☰)
  • Cliquer sur "New Map!" ou appuyer sur Ctrl+R
  • Une nouvelle carte se génère (différente)
  • Pas d'erreur dans la console

🔍 Test 4: Zoom et Pan

🟡 Navigation
  • Zoom avec la molette de souris (fonctionnel)
  • Zoom fluide sans lag
  • Pan avec cliquer-glisser (fonctionnel)
  • Pan fluide sans lag
  • Les labels disparaissent/apparaissent selon le zoom

🎛️ Test 5: Contrôles UI

🟡 Menu Layers
  • Cliquer sur "Layers" (bouton avec des couches)
  • Le menu Layers s'ouvre
  • Toggle "Borders" ON/OFF (frontières apparaissent/disparaissent)
  • Toggle "Rivers" ON/OFF (rivières apparaissent/disparaissent)
  • Toggle "Labels" ON/OFF (noms apparaissent/disparaissent)
🟢 Menu Options
  • Cliquer sur "Options" (⚙️)
  • Le menu Options s'ouvre
  • Les paramètres sont visibles et accessibles
🟢 Menu Style
  • Cliquer sur "Style" (🎨)
  • Changer un style (ex: "Heightmap", "Political")
  • La carte change d'apparence

🛡️ Test 6: Gestion d'Erreurs (Nouveau!)

🟡 Test de Robustesse

Ces tests vérifient que les corrections fonctionnent:

  • Générer 5 cartes différentes (Ctrl+R × 5)
  • Aucun crash visible
  • Dans la console: pas d'erreurs "Critical error in drawFeatures"
  • Si erreur "Failed to draw feature X" → skip et continue (NORMAL)

ℹ️ Les nouvelles corrections permettent de skip les features problématiques au lieu de crasher

⚡ Test 7: Performance

🟢 Test de Performance

Dans la console, taper:

perf.logMetrics()
// Affiche les métriques de performance
  • Exécuter perf.logMetrics() dans la console
  • Vérifier "svgElementsTotal" (nombre d'éléments)
  • Génération de carte < 5 secondes
  • Zoom/Pan fluide (pas de lag majeur)

🧹 Test 8: Cache Fix (Bonus)

🟢 Tester l'Outil de Nettoyage
  • Ouvrir CLEAR-CACHE.html
  • Cliquer "Clear All Cache"
  • Vérifier qu'il détecte et supprime les caches
  • Recharger l'application (Ctrl+Shift+R)
