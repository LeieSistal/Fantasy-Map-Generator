## 📊 **SANS CONSOLE - Comment Vérifier**

### ✅ **Méthode Visuelle**

**La carte fonctionne SI:**
1. Vous voyez des **zones vertes/brunes** (terres)
2. Vous voyez des **zones bleues** autour (océan)
3. Vous voyez des **lignes de frontières** entre pays
4. Vous voyez des **noms** écrits sur la carte
5. Vous pouvez **zoomer** (pincer pour zoomer)
6. Vous pouvez **déplacer** la carte (glisser avec le doigt)

**La carte EST CASSÉE SI:**
1. Vous ne voyez QUE du bleu (océan)
2. Pas de terres visibles
3. Les boutons du menu ne répondent pas

## 🔧 **POUR ALLER PLUS LOIN (Optionnel)**

### Si vous voulez vraiment voir la console sur iPad:

**Option A: Inspect Browser (App)**
1. Télécharger "Inspect Browser" depuis l'App Store (gratuit)
2. Ouvrir l'app
3. Aller sur votre site
4. Taper l'icône "<>" en bas pour voir la console
5. Chercher des erreurs rouges

**Option B: Safari Remote Debug (avec un Mac)**
1. Sur iPad: Safari → Réglages → Avancé → Activer "Inspecteur Web"
2. Connecter iPad au Mac avec câble
3. Sur Mac: Safari → Develop → [Votre iPad] → [L'onglet]
4. Console s'ouvre sur le Mac

**Option C: Eruda (Console Web)**
Je peux ajouter un outil de console directement dans la page web si besoin.
